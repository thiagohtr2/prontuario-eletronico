# P5 — Conecta · Escolhas feitas no Design System Studio

Site auditado: http://127.0.0.1:4300/ (Atelier UI · Design System Studio), modo **Guiado**, perfil de navegador limpo (`perfil/`), viewport 1440×900. Data: 02/11/2026.

Legenda: os nomes entre aspas são **exatamente** os textos mostrados pelo Studio. "LACUNA" = o Studio não oferece forma estruturada de configurar a característica. "Texto livre" = só foi possível registrar em campo de texto livre.
